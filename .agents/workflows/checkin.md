# Workflow: Check-in

Este workflow se activa cuando el usuario solicita realizar un "checkin".

## Instrucciones para Antigravity

1.  **Lectura de Contexto:**
    *   Lee el archivo `planmaestro.md` para recordar el contexto global, arquitectura y objetivos del proyecto.
    *   Lee el archivo `todo.md` para ver el estado actual de las tareas pendientes.
    *   Lee el archivo `sessions.md` para revisar lo realizado en la última sesión.
2.  **Sincronización:** Resume brevemente lo que has entendido del estado actual del proyecto basándote en la lectura anterior.
3.  **Priorización:** Pregunta al usuario: "¿Qué tareas del `todo.md` vamos a realizar primero en esta sesión?"
